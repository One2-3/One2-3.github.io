{{/* home_widgets_lang.html — 언어별 .Site만 사용, 경로 기반, leaf/section 모두 지원 */}} {{- $ctx := .ctx -}} {{/* 1) 현재 언어(.Site)에서 home을 '경로'로만 찾는다: leaf(index) → section */}} {{- $home := or ($ctx.Site.GetPage "/home/index") ($ctx.Site.GetPage "/home") -}} {{- if not $home -}}

위젯 섹션을 찾을 수 없습니다.

{{- else -}}
{{/* 2) leaf면 .Resources, section이면 .Pages */}} {{- $widgets := cond (eq $home.Kind "section") $home.Pages ($home.Resources.ByType "page") -}} {{- if not $widgets -}}{{- $widgets = $home.Resources.Match "**.md" -}}{{- end -}} {{/* 3) widget 지정된 것만 weight 오름차순 */}} {{- $widgets = where $widgets ".Params.widget" "!=" nil -}} {{- $widgets = sort $widgets "Params.weight" "asc" -}} {{- if not (gt (len $widgets) 0) -}}

위젯 섹션을 찾을 수 없습니다.

{{- else -}} {{- range $w := $widgets -}} {{- $name := lower (printf "%v" (index $w.Params "widget")) -}} {{- $partial := printf "widgets/%s.html" (replace $name "." "_") -}} {{- if templates.Exists (printf "partials/%s" $partial) -}} {{- partial $partial (dict "page" $ctx "widget" $w) -}} {{- else -}}
Missing widget: {{ $name }}
{{- end -}} {{- end -}} {{- end -}}
{{- end -}}
