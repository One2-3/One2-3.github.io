{{/* 1) 현재 언어의 home 디렉터리에서 widget 있는 페이지만 수집 */}} {{- $widgets := where .Site.RegularPages "File.Dir" $dir -}} {{- $widgets = where $widgets ".Params.widget" "!=" nil -}} {{- $widgets = sort $widgets "Params.weight" "asc" -}} {{- if not (gt (len $widgets) 0) -}}

{{- else -}} {{- range $w := $widgets -}} {{- $wname := lower (printf "%v" (index $w.Params "widget")) -}} {{- $partial := printf "widgets/%s.html" (replace $wname "." 알 수 없는 위젯: {{ $wname }}
{{- end -}} {{- end -}} {{- end -}}
